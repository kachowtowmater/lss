# Test fixtures

Captured on gpu-box 2026-09-19. No API keys anywhere; the gate log carries key NAMES only.

| file | origin |
|---|---|
| `sglang_metrics.txt` | REAL: one `curl localhost:8090/metrics` scrape (SGLang `0.0.0.dev1+g30705c004`, the served model, TP4) |
| `nvidia_smi.csv` | REAL: the collector's exact `nvidia-smi --query-gpu=…` command |
| `nvidia_pci.csv` | REAL: `nvidia-smi --query-gpu=index,pci.bus_id` |
| `gate_log.txt` | first 9 lines REAL (`docker logs -t <your gateway container>`; the container had been recreated minutes earlier so that is all there was), non-loopback IPs scrubbed to 192.0.2.10. The rest is SYNTHETIC in the exact `audit()` format the gateway uses, with its real verdict vocabulary, with documentation-range IPs; the last three lines are deliberately malformed |
| `journal_xid.txt` | lines 1 and 3 are REAL Xid 8 reports from this box's kernel log; the rest is synthetic (other Xid numbers, `-0700` offset form, unknown PCI address, noise lines) |
| `status_golden.json` | GENERATED by the `/status` golden test (`LSS_BLESS=1 cargo test -p lss-core golden`) |

Added with the USERS / TOKENS / MODEL pages:

* `gate_health_v52.json`, `gate_log_v52.txt`: SYNTHETIC, written from the gateway v5.2 schema
  (`users[]`, `totals`, and `est_tokens` / `completion_tokens` / `ttfb_ms` on every audit line).
  Addresses are from the documentation ranges, key names are made up.
* `benchmark_results_sample.json`: REAL output of `llm_decode_bench.py` v0.4.29 (decode at 1 and
  4 users, prefill at 8k / 64k / 128k), reduced to what the scorecard reads: the per-request
  samples and the startup diagnostics (host name, kernel, driver parameters) were removed.
